# 번역 프록시

앱의 유일한 백엔드다. 하는 일은 하나 — 요청을 받아 **서버가 보관한 키**를 붙여
Anthropic으로 넘긴다. 이게 없으면 사용자가 설정 화면에 자기 API 키를 넣어야 하고,
아무도 그러지 않는다.

## 왜 이렇게 생겼나

남의 회사 단톡방이 이 코드를 지나간다. 그래서 로직보다 **약속**이 중요하다:

| 약속 | 어떻게 지키나 |
|---|---|
| 대화를 기록하지 않는다 | 프롬프트도 응답도 로그에 남기지 않는다. 에러일 때도 |
| 누가 썼는지 모은 적 없다 | 저장하는 건 IP가 아니라 **소금 친 해시**다. 하루 뒤 만료된다 |
| 업스트림 에러 본문을 흘리지 않는다 | Anthropic 400 응답은 프롬프트를 되돌려줄 수 있다. 코드로 바꿔 내보낸다 |
| 남의 사이트가 이 키를 못 쓴다 | `ALLOWED_ORIGINS` 밖 요청은 모델 호출 **전에** 막힌다 |
| 한 명이 한 달 예산을 못 태운다 | 할당량을 모델 호출 **전에** 차감한다 |

마지막 두 줄의 "전에"가 핵심이다. 막는 게 호출 뒤면 이미 돈이 나간 것이다.
`worker.test.mjs`가 이 순서를 실제로 검증한다.

## 올리기

```bash
cd server
npx wrangler kv namespace create QUOTA        # 나온 id를 wrangler.toml에 넣는다
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put QUOTA_SALT            # 아무 긴 랜덤 문자열
npx wrangler deploy
```

그 다음 앱에 주소를 알려준다 — `app/js/translate.js`의

```js
export const PROXY_URL = '';   // ← 배포된 워커 주소
```

비어 있으면 앱은 프록시가 없는 것으로 보고 아티팩트 경로나 본인 키로 내려간다.
**즉 이 값을 안 채우면 지금까지와 똑같이 동작한다** — 서버는 선택지를 하나 더
얹는 것이지 기존 경로를 갈아치우지 않는다.

## 비용

세션(하루치 대화) 하나에 대략 $0.02. `DAILY_LIMIT = 20`이면 한 사람이 하루
최대 ~$0.4까지 쓸 수 있다. 사용자 100명이 주 3회면 월 $12 언저리다.

모델은 `wrangler.toml`의 `MODEL`로 바꾼다. 기본값은 정확도가 가장 높은
`claude-opus-5`이고, 비용을 낮추려면 `claude-sonnet-5`나 `claude-haiku-4-5`로
내릴 수 있다 — 다만 번역 품질이 이 앱의 전부이므로 내리기 전에 직접 비교해보길
권한다. 짧은 대화체 번역이라 추론이 필요한 작업은 아니어서, effort는 이미
`low`로 고정돼 있다.

## 테스트

```bash
node server/worker.test.mjs
```

업스트림은 가짜로 갈아끼운다. 네트워크도, 키도, 돈도 들지 않는다.
